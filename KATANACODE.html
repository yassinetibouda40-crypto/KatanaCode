    FAQ
    

    Is my code run on a server?
    No. It runs in a sandboxed iframe in your browser with a 3-second timeout.
    

    Which languages run?
    JavaScript runs in a browser sandbox. Every other language has lessons too, but your answer is checked by pattern matching and the code is not executed. Real execution needs a runtime or a backend, which is not built yet.
    

    Is there an AI tutor?
    Not in this build. It needs a server-side API key, so it is not faked here.
